# Ventanas actuales de Asterion System

Capturas reales de la APK Android debug en un emulador Pixel 6 con Android 16.
Fecha: 14 de noviembre de 2026. Se usó un perfil local de ejemplo («Cazador demo»)
para mostrar las rutas que requieren registro; no se usaron maquetas.

| Recorrido | Capturas |
| --- | --- |
| Acceso, cuatro pasos de registro e inicio | [Lámina 1](01_registro_y_inicio.jpg) |
| Navegación, planificador, progreso, ajustes, perfil y calendario | [Lámina 2](02_navegacion_y_perfil.jpg) |
| Misiones, rutinas, sesión guiada y ficha con GIF | [Lámina 3](03_misiones_rutinas_y_gifs.jpg) |

Las 28 capturas PNG a resolución completa se publicaron en el
[artefacto del recorrido instrumentado](https://github.com/miguelpinto9988-byte/Asterion-System-Android/actions/runs/43653648289/artifacts/14137546417)
(retención del artefacto de CI: 14 días). El recorrido terminó con `OK (1 test)`.
Las láminas de este directorio quedan en el repositorio como referencia para
el futuro trabajo de diseño.

La ficha con GIF representa un fotograma de la animación reproducida en la app.
